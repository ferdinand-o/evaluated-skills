# impl-plan Implementation Plan

**Goal:** Pläne, die `subagent-dev` lesen kann — eine dünne Skill für die Schreibseite
und ein Repo-Test, der jeden neuen Plan im falschen Format rot macht.

**Architecture:** `impl-plan` ist Tier 1 ohne eigenes Skript: Template, Ablauf,
Prüfliste. Der Code dieser Spec liegt in `subagent-dev` (vier Erweiterungen an
`plan_to_tasks.py`) und in `tests/` (der Repo-Test). Der Parser bleibt beim
Konsumenten; jede Format-Erweiterung wird dort gebaut und getestet.

**Tech Stack:** Python 3.13 Stdlib für die Erweiterungen und den Test; Markdown für
Skill, Template, References, Evals.

**Spec:** `specs/Spec 16 – impl-plan.md`, gebunden an `specs/Spec 00 – skill-foundation.md`.
Eingabe der Spec: `docs/assessment-writing-skills-writing-plans.md` auf Branch
`claude/assessment-writing-skills-plans`.

## Global Constraints

- **E1 — Parser bleibt bei `subagent-dev`.** Kein Import zwischen Skill-Skripten, keine
  Kopie des Parsers. `impl-plan` ruft `plan_to_tasks.py lint` auf.
- **E2 — Tier 1 ohne eigenes Skript**, mit Degradationszeile: ohne das Skript gilt der
  Plan als „ungeprüft", und das wird bei der Übergabe gesagt.
- **E3 — Gate-Sprache.** Lint und Repo-Test sind G2 („meldet", „macht rot"); die
  SKILL.md verlangt (G1). Nirgends „blockiert".
- **E4 — Vokabular additiv und fail-closed.** `fn:`, `token:`, `file:` kommen dazu,
  nackte Bezeichner bleiben, alles andere bleibt unbekannt. Symbole tragen eine `kind`;
  `verify` prüft nach `kind`.
- **E5 — Legacy-Menge nach Dateinamen**, nicht nach Befund-Zahl. 16 Pläne, nicht
  gelintet; die Menge darf nur schrumpfen.
- **E6 — Kein Eval hängt am Lint.** Der Lint ist im Eval-Workspace nicht vorhanden
  (`evalkit/workspace.py::prepare()` kopiert nur das Skill-Verzeichnis). Evals hängen an
  der Kopfzeile, den kanonischen Titeln und dem Vokabular im Plan; Pfade sind Globs; keine
  Fixture bringt etwas unter `docs/superpowers/plans/` mit.
- **E7 — Template ist lint-sauber:** keine Platzhalterwörter, `**Spec:**` zeigt auf
  Spec 00.
- **E8 — Zirkularität:** Dieser Plan entsteht vor Template und Vokabular. Er ist im
  heutigen Format geschrieben und wird nach Task 1 erneut gelintet.
