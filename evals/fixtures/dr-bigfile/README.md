# stadtbibliothek

Bestandsverwaltung einer Stadtbibliothek: Leser, Medien, Ausleihen, Vormerkungen, Mahnungen,
Gebühren, Standorte und Inventur, je mit Suche, Prüfung und CSV-Austausch.

- `bibliothek/fehler.py` — Fehlerklassen der Bestandsverwaltung
- `bibliothek/bestand.py` — die Verzeichnisse und der Gesamtbestand
