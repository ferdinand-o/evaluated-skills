# Task-Manager

Ein kleiner Task-Manager. Aufgaben haben einen Titel, einen Status und
optional ein Fälligkeitsdatum (`src/tasks.py`). Bei bestimmten Ereignissen
sendet die Anwendung E-Mails über `src/email.py` und veröffentlicht Events
über `src/events.py`. Es gibt aktuell keinen Push- oder SMS-Kanal.
