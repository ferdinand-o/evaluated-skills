# Spec 21 – note-tag: Beispielspalte konkret

**Änderung:** In `skills/note-tag/references/tags.md` sind zwei Beispiele zu vage.
`#task` bekommt das Beispiel „Cache-Invalidierung bis Freitag schreiben", `#ref`
das Beispiel „Redis-Konfiguration, Stand Mai 2026". Sonst ändert sich nichts —
nicht die SKILL.md, nicht das Tag-Vokabular, keine neue Datei.

**Tier:** 0, bleibt so. Die bestehenden Evals bleiben gültig.
