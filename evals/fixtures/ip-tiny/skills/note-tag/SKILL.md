# note-tag — ein Tag pro Notiz

Jede Notiz bekommt genau einen Tag aus [references/tags.md](references/tags.md).
Keinen zweiten, keinen neuen. Passt keiner, bleibt die Notiz ungetaggt und
bekommt die Zeile `Untagged:` mit einem Wort Begründung.

## Ablauf

1. Notiz lesen, Tag aus der Tabelle wählen.
2. Tag als erste Zeile schreiben: `#idea`, `#task` oder `#ref`.
3. Fertig. Keine Zusammenfassung, keine Rückfrage.
