# Die drei Tags

| Tag | Bedeutet | Beispiel |
| --- | --- | --- |
| `#idea` | Etwas, das noch niemand entschieden hat | „Wir könnten die Suche cachen" |
| `#task` | Etwas, das jemand tun wird | „Cache-Invalidierung schreiben" |
| `#ref` | Etwas, das nur nachgeschlagen wird | „Redis-Konfiguration vom Mai" |

Ein Tag pro Notiz. Passt keiner, steht `Untagged:` mit einem Wort — nie ein
vierter Tag.
