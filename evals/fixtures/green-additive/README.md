# Fixture: green-additive

Leeres Projekt. Der Prompt bittet um eine neue Tabelle mit einer einzigen
nullable Spalte — additiv und locksicher in jeder Klassifikation. Pflicht-
Anti-Zeremonie-Eval (Spec 00 §2): die Skill muss ihren vollen
Gefahren-Vortrag (rot/gelb-Klassen, Mehrschritt-Pläne) hier weglassen, weil
keine dieser Gefahren zutrifft.
