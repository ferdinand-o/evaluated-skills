# fahrtenbuch

Fahrtenbuch eines Dienstwagens: Fahrten erfassen und prüfen, Kosten je Fahrer abrechnen,
Monats- und Jahresberichte ausgeben.

- `fahrten/` — Fahrten, Erfassung aus der Monatsliste, Prüfung vor der Abrechnung
- `kosten/` — Kilometersätze, Monatsabrechnung, Quartalsbudget
- `export/` — CSV, Monatsbericht, Jahresübersicht
